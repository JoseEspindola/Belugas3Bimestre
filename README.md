# Rick and Morty App

Aplicativo de catálogo para consultar personagens, ver seus detalhes e salvar favoritos.

## Contexto

Rick and Morty.

## API

Rick and Morty API: https://rickandmortyapi.com/api/character

## Tecnologias

Expo e React Native.

## Instalar e executar

```bash
npm install
npm start
```
